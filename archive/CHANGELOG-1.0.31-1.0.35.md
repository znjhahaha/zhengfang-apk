# 变更日志归档：1.0.31 – 1.0.35

本文件是从 [CHANGELOG.md](../CHANGELOG.md) 拆出的早期条目，**内容一字未改**，只移动了位置。

覆盖 1.0.31 – 1.0.35（均为 2026-05-26）。1.0.36 – 1.0.66 期间 CHANGELOG.md 未随版本更新（当时被 .gitignore 屏蔽），这一段的变更只能查阅 Git 提交历史；1.0.67 未发布，内容顺延至 1.0.68。当前最新版本为 pp/version.properties 中的 1.0.116。

## [1.0.35] - 2026-05-26

### 🔧 部署与流水线 (CI/CD)
- **支持手动构建**：在 GitHub Actions 的 `release.yml` 工作流配置中添加了 `workflow_dispatch` 选项。若因 GitHub 服务器事件丢失或其它原因未自动触发 Tag 动作，用户也可以在 Actions 控制台界面手动触发编译并发布 APK。

## [1.0.34] - 2026-05-26

### 🐛 问题修复 (Bug Fixes)
- **退课失败修复**：修复了由于使用未加密的原始 ID `classId` 提交退课请求导致后台拒绝操作的问题。现在已选退课接口已优先正确传递加密过的 `doJxbId` 选课标识。
- **课表分享崩溃修复**：修复了在导出并分享 `.ics` 课表文件时，由于共享文件处于缓存根目录而未在 `file_paths.xml` 中配置相应映射，导致 `FileProvider` 抛出 URI 异常引发的崩溃错误。

## [1.0.33] - 2026-05-26

### ✨ 体验优化 (UI/UX)
- **非线性展开动效**：将课程折叠列表的展开/折叠以及箭头的旋转动画，统一重构为高级非线性 Material 3 Emphasized 物理曲线（`MotionSpecs.emphasized`），大幅拉长了淡出和减速阶段的曲线尾流，使得界面在视觉上呈现极高的高级感与顺滑感。

## [1.0.32] - 2026-05-26

### ✨ 体验优化 (UI/UX)
- **已选界面重构**：重写了 `SelectedCoursesScreen`，背景换用系统级 `NeuSurface`，卡片重构为带阴影和光影效果的 `SystemCard`，且各项信息配以更直观的矢量图标。
- **对话框动画统一**：已选界面的“确认退课”对话框改用平滑的底部滑入渐显（`slideInVertically`）和轻柔渐隐（`fadeOut`）的过渡动画，与设置、课程详情等弹窗风格保持一致，弃用原有僵硬的系统 AlertDialog。
- **课程列表展开动画**：将课程列表的展开/折叠过渡动画从带有轻微弹跳的弹簧动画（`gentle`）调整为经典流畅的 `tween(300)` 配合 `FastOutSlowInEasing` 缓动，兼顾交互效率与流畅感。
- **课表空间与防遮挡**：微调了课表左右侧的时间列宽度（34.dp -> 28.dp），缩减卡片内边距至最紧凑水平，并还原了合理的字体阶梯，支持最多 6 行的文字展现，彻底解决了变宽后字符在窄屏幕下被裁剪的问题。

### 🐛 问题修复 (Bug Fixes)
- 修复了此前在已选课程页面执行退课操作后，列表缓存没有同步刷新，导致切回主页面列表状态不正确的持久化同步漏洞。

## [1.0.31] - 2026-05-26

### ✨ 体验优化 (UI/UX)
- **视觉重构**：优化所有按钮与分段控制器的文本垂直居中问题，移除强制裁切和人工位移，恢复 Android 原生完美对齐。
- **克制拟态**：精简基础按钮（主要/次要/危险按钮）的重度液态玻璃阴影，降低视觉负担，提升层级清晰度。
- **监控模块**：重构 `GrabPro` 界面监控目标的显示，解除了长课程名称被强行压缩进 StatusBadge 的限制，改用加大加粗的独立标题展示。
- **课程列表**：将课程列表项改为轻量级的玻璃卡片风格，并新增了授课教师和课程容量的精美图标指示（Person/Group），提升页面饱满度。
- **课表增强**：解除了原先课表格子内的行数限制和缩写强制（如不再强制截断校区），确保完整的课程名称与上课地点完整显示。
- **弹簧动效**：
  - 课表视图 (Timetable)：为课程色块增加了响应式物理按压缩放动画，手感更加真实 Q 弹。
  - 课程展开 (CourseList)：课程组的展开/收起过渡从僵硬的线性动画替换为了 `MotionSpring.gentle()` 弹簧阻尼引擎，并加入了平滑的 180 度箭头翻转动画，顺畅自然。

### 🐛 问题修复 (Bug Fixes)
- 修复部分设备上中文渲染因 `includeFontPadding = false` 导致的文字整体偏上问题。
