## 登录超时：已经修了什么

`PluginSandboxClient` 的“插件进程启动超时”表示绑定阶段未及时取得 `onServiceConnected`，不同于学校 HTTP 超时。原 10 秒预算仍在，不是把超时改大或移除隔离 UID。

绑定返回失败、空绑定、连接死亡可在尚未交付执行时恢复一次；超时会淘汰失效连接，防止下次继续等待同一坏连接。只要尝试向沙箱交付执行，即使 Binder 抛错也不自动重放。连接复用不共享 QuickJS 脚本全局状态。

本机诊断记录关联 ID、版本、阶段和耗时，区分排队、绑定、引擎加载、脚本、网络和响应校验。不会保存账号、完整 URL、请求参数、响应正文或凭证。日志入口复用现有本机错误报告。

**没有反馈设备的启动日志，因此无法确认为什么 Android 系统未回调，不能声称 94 版用户的无法登录已彻底解决。** Android 7 虚拟机与 Android 17 设备的观察不是严格性能对照。

课表获取与节次时间补充分开：非关键节次补充失败保留已获取课程；刷新失败保留旧缓存并显示原因与重试；有效空课表与异常区分。账号/学校/学期/适配变化后不接受旧结果。会话、安全与取消错误仍传播，不伪装成空课表。

## 授权与安全取舍

首次选择“允许并记住”后，同一账号、学校与有效身份连续刷新、重开和重新登录复用同意；重新登录仍创建新句柄，旧句柄不复活。“仅本次”表示当前登录会话。本地或缺少可信审核证明的包按调用方及提供者实际包摘要记住，换包确认一次。旧授权升级到更宽来源只补一次确认，不清除业务数据。

站点授权以协议、主机、端口为边界，不支持任意通配子域；认证材料发送范围另行受限。取消普通共享请求逐端点/逐次 mutation 弹窗，能减少已读更新和正文读取中的重复操作。

站点授权无法理解所有站内接口副作用。人工复核应检查选退课、评教、删除、支付是否绕过业务入口确认；宿主不能保证识别任意伪装请求。隔离 UID、凭证不导出、跨域跳转检查、资源限制、外传接收方授权及未知结果防重发保留。人工审核也不能代替用户同意把个人数据交给作者服务器。

不采用 #42 建议的长期“已检查”标记，因为等待期间可能撤销或切换账号；不拒绝全部重叠网络规则，合法的宽/窄认证头规则仍需要最长路径仲裁；不为减少文件数迁移合并三种不同生命周期的存储。

## 数据、窗口与兼容

details 最多 32 项；ID 唯一且最长 64，标签最长 40，值最长 2000，合计 16 KiB；周次须为课程条目子集。界面只显示文本，不执行 HTML 或加载远程资源。旧缓存按空字段读取；损坏扩展舍弃而保留课程。不同周内容合并时保留，重复导入不无限追加。提醒键与课程稳定 ID 不依赖备注。

通用正方/强智消费者使用新增的不可变协议库 3.2.3；金智和乘方学校插件保留此前锁定版本及受限标签。新增字段仅映射已有样本能支持的内容，合成样本不代表截图学校已经完成适配。

新字段需要 minAppVersionCode 96；ui.viewport@1 还需 requires 协商。旧插件继续运行，旧客户端目录不因 SDK 更新而获得不兼容包。网页能力白名单保持原有允许集合，新视口能力只供前台原生页面。

360/411 dp 保留原尺寸插值；600/840 dp 分档约束表单、列表和弹窗。原生插件页面会在配置重建期间内存保留状态、待处理确认和执行任务；进程重建不重放已提交命令。主登录输入在 ViewModel 内存保留，**正在进行的主登录会取消并提示重试**，不宣称验证码事务跨旋转继续。未将密码或 Cookie 写入系统 Bundle。
