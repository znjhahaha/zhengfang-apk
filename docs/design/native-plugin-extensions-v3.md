# 原生插件扩展 API v3

用户已选择原生扩展方向。保留本体内置教务协议、配置型/扩展型/独立教务插件，继续支持 API 1 和 2。

本次实现范围：

- 服务插件独立多页导航；新增键值信息、表格、时间线、柱状图、网格入口组件，表单增加多行文本和开关。
- 服务入口可声明投放到课程首页、课表页、成绩页；沿用原生玻璃按钮。插件没有安装或没有声明入口时保持现有页面。用户可在校园服务中心按账号隐藏或恢复入口。
- 扫码、文件选择、即时通知、日历编辑四种宿主操作。每次用户点选后先显示插件名称、用途和具体操作，再交给系统；拒绝不执行。未声明操作不能使用。
- 文件仅通过系统选择器读取本次选定内容，最大 64 KiB，不授予目录和持久 URI 权限；扫码只返回文字，不自动打开链接。结果仅回传声明的查询回调，不能借此跳过写操作确认。
- 通知明确标注插件来源。日历打开系统新增事件界面，由用户保存；打开编辑器不能声称日程已保存。
- 宿主操作前后核对账号、插件启用状态和服务会话。取消、会话变化、缺少权限和设备无对应应用均明确处理，不自动重试。

开发工具同步 Schema、类型、校验、API 3 模板、模拟样本和文档。新增模板保留为开发包，不标记为真实学校服务、不签名上架。

验证覆盖 JVM 契约边界、旧插件兼容、CLI 样本及打包、Compose 原生组件/授权拒绝/结果回传、设备可用时的系统入口。未实际验证的设备硬件能力单独记录。

本次不开放任意 Android 代码、全局导航替换、服务插件读取教务密码或 Cookie；跨插件数据授权另行定义。
