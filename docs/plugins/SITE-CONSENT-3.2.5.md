# 学校站点授权、查询诊断与插件卸载

本轮对应 Issue #41，以及查询后加载慢、教务适配缺少卸载入口的反馈。API 主版本仍为 3，配套 SDK 为 3.2.5。已安装 App 不会因源码变更自动获得修复；此交付不包含 APK 或线上部署。

## 授权行为

学校共享请求在用户一次明确授权后按准确来源（协议、主机、端口）放行常规 GET/POST，不再逐端点要求声明，也不要求通知更新必须改写成 query 或结构化 form。首次采用站点授权须明确同意，旧授权不自动扩大。记住的同意与会话句柄分开，关闭重开及同账号重登恢复同意并建立当前句柄。不同账号、不同学校、权限来源增加或不可信包变化不继承授权；缩小范围不重新询问。

本地包和缺少审核凭证的签名包按调用方及认证提供者的包摘要记住信任。可跨更新的发行身份需要内置身份或签名目录中绑定确切包、源码与权限摘要的审核证明。清单自报审核不生效，预发布包签名不是审核证明。并发授权共用一次问题，包括拒绝结果。

保留账号/学校/版本/撤销检查、凭证句柄、来源与跳转校验、认证响应端点限制及令牌自身发送范围。**（2026-10 订正：本段原文在「撤销检查」后还列有「隔离 UID」，但 1.0.96 起插件服务与主 App 共用同一 UID、不再有隔离 UID，故已从当前项中移除；该变更见 `CHANGELOG.md` 1.0.96 条目与 `docs/ISSUES-50-51.md`。）**选退课、service.action 和 workflow 的业务确认、防重发逻辑继续执行；共享的普通状态更新可随页面刷新执行。站点授权无法判断所有学校接口的副作用，人工审核必须核对高风险业务入口，不能声称宿主能识别任何伪装请求。个人数据外传仍按接收方、类别及用途单独授权。

## 查询与运行生命周期

HTTP 连接池按插件、包、账号会话与来源隔离，Cookie/Token、权限检查和请求上下文不缓存进连接池。同一页面复用隔离服务连接；引用清空后最多空闲 30 秒。启动超时或连接死亡淘汰旧连接，后续请求可重新绑定。每次仍创建独立 QuickJS 引擎，APK 契约与 SDK 文本复用不可变缓存。用户授权等待有独立时限，不占用业务执行预算。

PluginNetwork / PluginSandbox / PluginUi 的阶段记录包含系统 API、插件版本、阶段和耗时，不记录完整 URL、查询参数、请求或响应正文。可区分排队、绑定、引擎初始化、网络连接、TLS、响应到达、读取及结果回传。没有统一延长超时，也不自动重放可能提交的写入。

## 卸载

开发者页面与插件中心共用卸载逻辑，教务适配也提供入口；真正内置包显示停用。卸载当前或其他学校使用的适配时，恢复明确对应的内置适配；不存在时标为未配置，不选其他协议。保留学校配置、缓存课表成绩和待核对的工作流记录。撤销授权、取消直接与共享的在途调用，并保留撤销代次，避免重装后旧回调恢复权限。恢复内置适配与卸载分别显示。
