# 正方教务助手宣传视频设计规格

## 目标

制作一支约 45 秒的横版产品宣传片，介绍“正方教务助手”的核心功能与液态玻璃 UI/UX。成片应首先让观众感受到产品的精致、轻盈和现代感，随后用真实应用画面证明它能解决课程浏览、抢课、课表与成绩查询等高频需求。

## 受众与发布场景

- 主要受众：使用正方教务系统的高校学生。
- 主要场景：项目主页、发布页、社交媒体横版视频与产品演示。
- 主输出：1920 x 1080、30 fps、H.264 MP4、约 45 秒。
- 音频：电子氛围音乐与克制的 UI 音效，不使用旁白。
- 语言：简体中文。字幕短、强、可在静音播放时独立成立。

## 创意主张

核心文案为：

> 让每一次选课，都更从容。

功能叙事与视觉叙事并行：功能线强调“浏览、筛选、抢课、课表、成绩”；视觉线强调“真实折射、动态模糊、镜片响应、弹簧反馈、信息层级”。视频不把液态玻璃描述成装饰，而是表现它如何帮助用户辨认状态、聚焦当前操作并保持页面轻盈。

## 视觉语言

- 基调：冷白、冰蓝、青色，辅以少量珊瑚红和暖黄作为状态提示。
- 背景：从 App 的动态壁纸与柔和色场中取样，使用缓慢漂移的光影，不使用无意义的装饰球体。
- 玻璃：半透明层、折射高光、轻微色散、景深变化与真实界面素材结合。
- 字体：清晰的现代中文无衬线体。标题有较强字重，功能说明保持短句。
- 动效：弹簧进入、镜片滑动、轻微视差和局部放大。镜头持续运动，但不追求高速炫技。
- 设备展示：真实 App 截图与录屏置于无边框手机画面中；关键控件可越过设备边界短暂放大，以便展示折射和响应细节。
- 隐私：账号、课程私人信息、成绩明细、Cookie、学校身份和设备标识全部隐藏或使用演示数据。

## 分镜与节奏

### 0:00-0:04 开场：轻盈登场

黑场中出现一道冷白折射光，扫过应用图标。玻璃表面凝聚出“正方教务助手”，副标题为“开源 · 免费 · 安全”。音乐从空气感脉冲进入。

### 0:04-0:10 UI/UX：不只是透明

真实首页从背景中浮现，镜头靠近胶囊底栏和玻璃卡片。三组短文案依次出现：

- 真实折射
- 动态模糊
- 触控有回应

底栏镜片在 Tab 之间弹簧滑动，按压高光跟随触点。背景色穿过玻璃时产生亮度与色彩变化，说明 UI 的层级和反馈价值。

### 0:10-0:17 课程：更快找到目标

展示课程列表、搜索和筛选。镜头从搜索图标转到筛选条件，再落到课程余量和教师信息。文案：

> 搜课程，看余量，筛到刚刚好。

### 0:17-0:25 抢课：三种策略

三种模式以分段节奏出现：立即抢课、定时抢课、捡漏监控。队列状态与操作反馈用清晰的状态色表示。文案：

> 立即 · 定时 · 捡漏

补充短句：

> 把时机，交给更可靠的流程。

### 0:25-0:32 课表：一周一目了然

彩色周课表展开，课程块以错峰弹簧动效进入。镜头强调周切换、课程自动配色与日历导出。文案：

> 课表、地点、时间，一眼掌握。

### 0:32-0:38 成绩与考试：结果集中查看

展示学期切换、成绩概览、GPA 和考试安排。玻璃选择器平滑展开并吸附到目标学期。文案：

> 成绩、GPA、考试安排，一处查看。

### 0:38-0:42 安全与适配

以三个简洁信息点收束产品可信度：

- 临时 Cookie 凭证
- 多校适配
- 开源透明

避免宣传绝对安全；只陈述项目当前实现和可核实能力。

> 让每一次选课，都更从容。

## 素材策略

- 优先使用本地模拟器重新采集的最新画面，确保与当前代码一致。
- 现有 `pic` 截图只用于功能理解或在无法生成演示数据时补充。
- 重新采集胶囊底栏切换、课程筛选、液态选择器、课表与成绩页面。
- 截图和录屏不得出现真实账号、身份、Cookie、真实成绩或个人课表。
- 应用图标使用项目内最高分辨率资源。
- 背景音乐须来自允许再分发的来源，并在交付说明中记录来源与许可。

## Hyperframes 实现

- 使用 Hyperframes 的 product-launch-video 工作流。
- 使用 HTML/CSS 构建 1920 x 1080 组合，并用可定位、可重复渲染的动画时间线驱动镜头。
- 本地媒体全部冻结在视频项目目录中，不依赖渲染时网络请求。
- 场景采用独立片段，统一由主组合管理时长、层级和音轨。
- 保留 Hyperframes 源工程、设计说明、素材清单与渲染命令，方便后续修改文案或重新输出。

## 验收标准

- 时长 42-48 秒，1920 x 1080，30 fps，H.264 MP4。
- 首屏四秒内出现产品名称或清晰产品信号。
- 液态玻璃 UI/UX 至少占一个完整段落，并以真实交互画面支撑。
- 课程、抢课、课表、成绩四类核心功能均有明确视觉证据。
- 全片中文文案无错字、无遮挡、无越界，关键字幕至少保留 1.5 秒。
- 不出现个人账号、凭证、真实成绩或其他敏感信息。
- 音乐、UI 音效和画面切点协调，峰值音量不过载。
- 随机抽取开场、中段和结尾帧，确认画面非空、素材无缺失、颜色与构图正确。
- 最终交付包含 MP4、Hyperframes 源工程、素材清单、技术参数、使用说明与版权信息。

## 范围边界

- 本次只制作横版主宣传片，不同时制作竖屏裁切版。
- 不修改 App 功能或 UI 实现；如模拟器数据不足，只创建用于拍摄的本地演示状态。
- 不承诺未经验证的学校覆盖范围、抢课成功率或绝对安全性。
- 不加入真人出镜、AI 数字人或旁白。
