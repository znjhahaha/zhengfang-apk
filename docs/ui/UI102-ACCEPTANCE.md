# 1.0.102 页面过渡、弹窗与成绩状态

本轮从 App main `b5bb423` 创建 `fix/page-transitions-grades-102`，仅修改 App 内部实现。开发版本为 **1.0.102 / code 102**，正式发布仍为 **1.0.101**；SDK **3.2.8**、API **3** 及插件契约不变。

## 实现

### 首次进入页面

`InitialPageLoad` 分开管理后台准备、页面挂载和首屏就绪。导航结束后挂载一次真实页面，课程、课表和成绩分别报告可展示缓存、成功、有效空结果或错误。抢课工作台从本地队列、配置恢复完成即可展示；设置和通用插件入口在准备完成后展示。

等待期间使用静态骨架，正文就绪后用 180 ms 透明度过渡替换。隐藏正文不接收点击或辅助功能焦点；骨架上的准备失败重试按钮仍可操作。首次进入取消重复模块入场，返回已进入页面沿用既有导航动画。减少动态效果开启时直接替换。教学班、筛选及其他补充请求不延长已可展示的首屏。

`ReportInitialPageReady` 独立于只统计非空内容的 `ReportPageContent`，因此空数据及错误不会永久留在骨架。准备任务随页面失效取消，不把前一个账号的准备状态复用到新账号。

### 弹窗及成绩文字

- 弹出面板底色透明度为浅色 0.78、深色 0.84、高对比度 0.96；关闭玻璃使用不透明主题底色。常驻卡片、底栏材质不变。
- 保留模糊、折射、宽度约束及连续圆角。标题与正文左对齐，正文使用主题前景色，主按钮实色强调、次按钮中性底、危险按钮危险色。
- 同窗口遮罩和独立窗口回退共用 0.22 压暗值。简单长文本确认启用可滚动正文；已有滚动列表保留自身滚动，避免嵌套无限高度。
- 成绩 `MeasuredGradesHeader` 使用 `refractLabels=false`，文字退出折射采样，在玻璃上方只绘制一次。保留滑块、按压、顶栏收起、学期胶囊宽度及点击语义。

### 成绩浏览偏好

`GradeBrowsePreferences` 保存原始学期 ID、显示名及分段。作用域由账号存储键、学校、成绩提供者稳定 ID、学期编号格式组成，不使用会话代次或包摘要。插件和旧版成绩路径共用保存/恢复逻辑。

恢复优先使用当前页面保存状态，其次本地偏好；无记录时才应用学校或本地默认。用户选择立即写入偏好。迟到目录、总体成绩、日期变化或失败不能覆盖显式选择；请求结果核对会话及请求学期。目录暂时缺项时保留已选名称和可用缓存，提示刷新或重新选择，不猜测不透明 ID、不自动跳转学期。普通退出保留偏好，删除账号清理该账号所有成绩浏览作用域。

旧版本不需要迁移或清缓存；升级后的显式选择开始持久保存。

## 后续修正：1.0.103

102 测试包反馈发现，下拉菜单也调用了 `modalSurfaceAlpha`，因此意外继承弹窗加深的底色。103 将菜单改用独立 `dropdownSurfaceAlpha`，恢复浅色 0.18、深色 0.22、高对比度 0.96；弹窗和课程详情面板保留本轮调整。菜单宽度、展开动画、关闭玻璃及自定义壁纸分支不变。相关回归检查同时约束菜单与弹窗的各自参数，防止再次混用默认值。此前“仅作用于弹窗”的范围核对遗漏了这一调用点。
