过程中的失败保留在交付证据：

1. `ui104-compile`：Material3 1.4.0 的 MotionScheme 为 Kotlin internal，直接调用编译失败。改用公共 Compose spring，局部区分空间与效果；没有反射或压制可见性检查，没有升级依赖。这是对原计划“直接使用已有M3E接口”的实际限制。
2. `ui104-focused`：23项中18通过、5失败。面板重定位时普通动作组持续布局，触控测试还把可见图形宽度当成触控宽度。
3. `ui104-panel-debug`：单项定位复现；锚点空间已稳定，排除空间上下翻转。移除临时日志，改用现成工具栏动作模式后，`ui104-focused-2` 23项全部通过。
4. 再补窄屏触发按钮不位移的回归并限宽，最终 `ui104-final` 24项全部通过。

静态检查：`git diff --check`、源码私有路径/秘密模式检查通过；市场业务前段/对话框后段逐字比对，公共玻璃配方、选择器、TopBarActionRail、主导航动效和NativePluginRenderer与main相同。
