# UI105 验收报告

> **历史文档。** 本文是 1.0.105（uipreview / SDK 3.2.8）的验收记录，其界面对应的正式发布走 1.0.109（SDK 3.2.9）——见 [UI109 稳定性说明](UI109-STABILITY.md) 与 [UI107 文字透镜与通用网页](UI107-COMPONENTS.md)。当前正式版为 1.0.116、宿主 SDK 为 3.6.0。原文保留。

日期：2026-10-05。开发版本 **1.0.105 / 105**；分支 **uipreview**；基线 `177886de2f8498209a329382ef4b5b4739c661cf`。
SDK **3.2.8**、API **3** 不变。本轮仅 App 内部组件与界面修复。

## 代码已修复

| 用户反馈 | 改动 |
| --- | --- |
| 点击插件筛选原生闪退 | 搜索、筛选、更多采用稳定按钮＋同窗口独立浮层。正文不再在被采样页面内短暂挂载或回迁，尺寸未就绪不绘制；保留无宿主时的实色回退。 |
| 成绩／插件分段滑块消失或不明显 | 文字继续只绘制一次，移除空文字采样。以实际背景绘制状态决定回退，补充静止选中底色；保留滑块运动和背景折射路径。 |
| 更多菜单仍是原生样式 | 使用课表 SystemActionMenu；保留忙碌禁用，关闭后单次执行操作，页面销毁后丢弃待执行回调。 |
| 收起后有多余遮罩 | 列表、玻璃底板、前景控件分层，列表从顶栏后经过；去除父级矩形底色和额外分段轨道，保留状态栏可读性处理。 |
| 类型筛选样式不统一 | 独立玻璃胶囊，选中底色与勾选、48 dp 触控区、大字体换行；学校入口及“仅本校”使用同一组件。 |

界面动效继续使用现有公开 Compose 弹簧：空间变化 .9/700，颜色与透明度 1/1600；菜单复用课表开合参数。胶囊预留勾选位置，避免切换造成宽度跳变。借鉴玻璃容器和清晰前景分层；没有升级 Material3 依赖或声称获得 M3E／Apple 的完整实现认证。

当前已经消除这条浮层路径中的自采样结构风险，但没有用户设备的 native stack/tombstone，不能断言这是其 SIGSEGV 的唯一原因。新增本机面板阶段、渲染路径及像素尺寸诊断，不记录搜索词、账号、URL、凭据或插件业务内容。
