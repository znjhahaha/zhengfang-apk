# UI106 内部组件与状态说明

版本 1.0.106 / 106，SDK 3.2.8、API 3 不变。以本说明替代 UI104/UI105 中浏览器浮层和分段底图的旧描述；旧报告保留作为历史证据。

## 单一浏览器浮层

`GlassSearchFilterPanel` 接收同一份可保存的 `BrowserPanel?` 和可选 `moreActions`。插件中心和组件预览均将三个入口接入这一个实例，不再同时登记搜索/筛选和更多两个独立浮层。未提供 `moreActions` 的旧内部调用保持搜索/筛选模式。

```kotlin
GlassSearchFilterPanel(
    panel = panel,
    onPanelChange = { panel = it },
    moreActions = actions,
    search = { SearchInput(query, onQueryChange) },
    filters = { FilterOptions(type, school, onFilterChange) }
)
```

示例中的 SearchInput/FilterOptions 是调用方的内容插槽。组件本身不请求目录、不安装插件，也不复制查询条件。布局中的条件摘要打开同一面板；条件改变仍使用原有列表位置重置规则。

三个 48 dp 触控单元分别报告窗口坐标，浮层从当前按钮定位。只有锚点和安全区域有效后启动动画。正文按照最终宽度和可用高度测量，独立外层裁剪负责展开；文本不能被动画中的窄条约束重新排版。窗口/键盘限制下，正文可以滚动。

`BrowserPanelPresentation` 在覆盖层的子组合内部读取当前面板、尺寸、透明度与操作状态，避免跨层传递的内容闭包继续使用上一版筛选正文或动画初值。

正文仅由 `GlassOverlayHost` 在采样页面的兄弟节点绘制，关闭和回退期间不会回迁。旧面板关闭只影响对应选择，菜单动作在关闭完成后执行一次；重开或销毁取消未执行动作。课表继续使用 SystemActionMenu，菜单行内容共用，旧下拉选择器不更换材质。

## 分段底图

`refractLabels=false` 保留真实前景文字和单份可访问语义。新 `SegmentMaterialSource` 只在小范围记录经模糊与中性底色处理的背景，不包含文字、滑块或按钮。API31/32 的离屏读回和 API33+ 的 runtime lens 使用同一个局部来源，不再直接用原始页面画面填充滑块。

局部来源记录位于控件的稳定坐标中；来源版本或几何变化时，过期帧不得用于新区域。等待、失败时继续显示普通背景和选中轮廓。默认会折射文字的其他控件不采用本次新来源策略；103 的下拉栏配方保持。

## 课表反馈

`ScheduleLoadIssue` 区分登录过期、网络、无效响应和其他失败；缓存的存在独立于课程条数，也独立于错误提示。

- 有缓存时自动发现登录过期：静默，保留课表。已知过期不反复查询。
- 手动同步：通过统一会话提示请求恢复，保留“稍后”。没有额外失败 Toast 或底部横幅。
- 无缓存：显示过期或失败原因及对应操作；有效空缓存按成功内容处理。
- 普通失败：保留缓存，可重试或关闭正文安全区域内的提示。

不更改账号凭据、自动恢复设置和请求的账号/会话校验。删除、刷新和切换学校仍遵循原有数据生命周期。

## 预览与边界

开发工具的“玻璃与收起页面预览”使用同一套三入口浮层与简洁条件摘要，继续提供长列表、空列表、失败、大字体、主题和减少动态效果开关。条目全为模拟数据。

这些都是 App 内部 Kotlin 组件，未新增 SDK 节点或插件能力。软件 Canvas/Compose 测试不能替代华为 API31、API32、Android17 真机 GPU、键盘和 TalkBack 验收。
