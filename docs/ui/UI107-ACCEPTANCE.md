## 修正过的验证失败

初次编译发现绘制导入与接收者限定问题；绘制测试随后修正了Canvas构造。42项初测中SPA片段被错误送进原生网络策略，修复为浏览器入口校验，保留原生HTTP策略。首次网页源码独立打包测试发现生成器缺少serviceScope，已补齐。最终上述回归通过；不将失败轮次计入通过数。
