# UI107：文字透镜与通用网页

开发版本 App 1.0.107 / 107，SDK 3.2.9，API 3。尚未正式发布。

## 分段文字的单一排版来源

成绩与插件中心显式采用 stableLabelRefraction。默认控件、课表日期和旧下拉选择器不启用该路径。

SegmentLabelSource 收集实际 Text 的 TextLayoutResult 与控件局部坐标，排版、尺寸或字体改变即更新版本；不复制一个隐藏 Text Row，不冻结包含可变子图层的绘制指令。背景透镜只读取局部材质。透明文字透镜单独位于背景、填充与高光之上，普通标签仅在透镜实际输出的区域避让。未取得可用帧时保留普通文字；API31/32 的透明层不绘制带过期文字的回退图。

相同的胶囊位置与按压形变用于玻璃、文字透镜和普通文字裁剪。只保留实际 Text 行的语义与手势。API33+ 使用同一局部字形来源，API31/32 异步采样使用现有来源版本与坐标失效保护。

## 通用网页容器

网页类型独立于业务分类。native 插件继续声明 contributes.pages / servers，页面 web.mode=browser 时无宿主 JS 桥，web.mode=bridge 或旧页面则沿用桥接。navigationOrigins 仅允许准确 HTTPS 顶层导航；桥接始终限定在原始服务来源和当前主文档。

PluginWebPolicy 集中导航、桥接及组件能力判断。纯浏览只要求隔离 Profile，不额外要求消息桥功能。PluginPageContent 的纯浏览生命周期不绑定教务 session token，仍绑定包、页面、服务账号及停用状态。网站 Cookie、storage 与教务凭据分离。菜单支持清理当前网站账号；确认后再次校验账号，退出该本地身份并退役对应 Profile，其他服务和账号的数据保留。

网页使用单个紧凑工具栏；独立 Activity 移除重复的外部标题，底栏页面复用相同容器。首次占位到真实内容为180ms淡入，减少动效时直接显示。网站内容不注入统一 CSS，不将 WebView 录入宿主玻璃采样。

历史状态仅在内存保留，至多8组，包含网页历史和滚动位置，不持有已销毁 WebView 或 Activity。页面退出释放 WebView；旋转/切页可恢复有效历史。新进程没有历史时要求重新打开入口，不恢复提交操作；WebView 的表单重发回调一律拒绝。发生网络或渲染进程错误时结束占位并提供恢复入口。

## 创建、校验与发布边界

CLI 的 web-browser 创建模式接收网址、名称、分类、图标与导航来源，生成配置和空业务模块。纯浏览没有业务方法时不伪造模拟案例；test 明确报告配置验证与0个业务场景，网站/device验收单独完成。源码交付包括插件自身配置与入口，不要求第三方网站源码。

最低 App code107 与 SDK3.2.9 契约门槛由 App、CLI 和网站审核共用源同步。审核规则版本2026-10-06.1；历史报告继续绑定原契约，不回写新结论。此轮只做本地网站构建与dry-run，不部署、不修改正式目录、不触发工作流。
