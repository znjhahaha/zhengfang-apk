# v1.0.101

## notes
- 选课列表支持手动加载更多，避免一次追完全部分页拖慢首屏。
- 可见课程渐进加载教学班和名额，提供展开全部、收起和失败重试。
- 修复教学班占位数量与未知名额显示，减少重复查询轮次和课程。
- 配额管理支持解绑非当前账号；登录页也可管理，保留保存账号和课表缓存。
- 新正方协议与 SDK 更新；广西大学独立插件需要维护者采用分页迁移补丁。
- 本版为待设备及实际学校验收的测试构建，公开正式更新提示保持原版本。
