# 1.0.102 开发版

本版本尚未发布；当前正式版本仍为 1.0.101。

## notes

首次进入课程、课表和成绩页面时显示静态页面骨架，当前首屏数据就绪后淡入；缓存、空结果和错误分别处理，后台补充查询不挡住首屏。
调整通用弹窗为更清晰的轻透磨砂面板，统一主次按钮和左对齐正文；为普通长文本确认提供可滚动内容区，并统一独立窗口回退的背景遮罩。
成绩分段栏的文字独立于玻璃折射绘制，保留滑块和顶栏动效，修复滚动时标签漂移、消失的绘制路径。
按账号、学校与成绩提供者记住成绩学期和分段。重启或同账号重新登录后恢复原选择；学期目录暂时为空或加载失败不会自动跳回当前学期。

## validation

SDK 保持 3.2.8，API 主版本保持 3。设备 GPU、Android 17 与实际学校验收另行记录，本地测试不能替代实机效果确认。
