# 1.0.109 分段文字稳定性修复

## notes

- 修复轻微拖动分段滑块时，文字颜色动画反复使折射快照失效的问题。
- 拖动期间保持字重，确认切换后再更新；松手后停止无效字形刷新。
- 局部底图后台刷新时保留兼容的折射帧，待新帧就绪后替换；尺寸、位置和字形变化仍作废旧帧。
- 保留文字放大、色散、自定义字体和成绩学期记忆。

## validation

开发版本，SDK3.2.9 / API3不变。实际GPU表现仍需华为API31、API32及Android17设备确认。

## stable notes

- 插件中心改为简洁列表与可收起顶栏，搜索、分类和学校筛选集中到浮层；优化首次点击、更多菜单、筛选胶囊及卡片信息排布。
- 优化成绩与插件中心分段滑块的文字放大、折射和色散，修复拖动时反复刷新字形导致的持续闪烁，保留自定义字体与成绩学期记忆。
- 有缓存课表时，自动刷新遇到登录过期继续展示课程；手动同步提供重新登录入口，减少重复失败提示。
- 新增通用网页插件：开发者配置网址即可接入学习、工具、社区等网站，支持多个入口、服务中心与固定导航，普通网页无需教务账号。
- 统一网页工具栏与加载过渡，提供前进、刷新、回到入口、外部浏览器和关闭操作；网站账号按插件和服务隔离，纯浏览模式不注入宿主桥。
- SDK 更新至 3.2.9，API 主版本保持 3；同步网页模板、开发者 Wiki、下载套件与插件审核工具链，旧插件保持兼容。
