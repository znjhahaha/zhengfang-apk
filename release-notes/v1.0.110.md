# 1.0.110 网页输入与启动首屏修复

## notes

- 修复网页插件打开输入法时，键盘上方出现大块空白、网页内容被遮挡的问题；网页底部现在贴合键盘上沿。
- 修复网页加载完成后输入框偶尔点不出输入法的问题；键盘开关和页面刷新不会重新加载网页或抢走焦点。
- 启动首屏统一为一份设置：设置页与服务中心的“设为启动页”显示并修改同一个选择，旧版本留下的服务中心启动设置不再覆盖设置页里选择的课表。
- 冷启动进入设置的首屏；后台切回、旋转屏幕时保留当前页面。通知、桌面组件和页面跳转仍可直接打开目标页，用过后不会影响下次启动。
- 修改启动首屏时，设置页不再重新加载，弹窗和滚动位置保持不变。

## validation

SDK 3.2.9 / API 3 不变。本地 JVM 回归与 Lint 通过；API 32 与 API 36 模拟器上的网页输入和启动首屏设备测试全部通过（含连续 20 轮键盘开关、手势与三键导航）。用户手机型号与输入法未知，真机上的偶发问题仍需设备确认。
