# 1.0.112 学习通插件宿主与签到交互完善

## notes

- 完善原生插件的多账号隔离、记录查询、前台任务和脚本管理，支持学习通课程、作业、考试提醒及签到监听；学习通插件需要单独安装。
- 补齐扫码、拍照、照片选择、位置选择和图片验证交互，支持普通、拍照、手势、签到码、位置、二维码及签退流程所需的宿主能力。
- 手势签到改为九宫格滑动绘制，显示连线轨迹并支持清空重画；松手后保存图案，确认按钮继续完成签到。
- 位置选择支持按活动地址搜索并在地图上确认；修复活动未返回经纬度时被误当成零坐标的问题，以及部分 Android 12 设备打开地图崩溃的问题。
- 上传保留照片文件名与格式，签到提交按活动限定授权范围；取消页面、切换账号或返回过期结果时不会继续提交，结果不确定的写入不会在后台自动重试。
- 增加内置浏览器和脚本任务控制，修复浏览器冷启动会话恢复、Cookie 隔离及重复打开后的连接问题。
- 修复插件页面底部内容遮挡、加载时布局跳动，以及未固定在导航栏的插件页面导致选中指示器越界的问题；完善滑块交互与无障碍操作。

## validation

SDK 3.4.0 / API 3。本地平台回归、App 插件宿主回归、SDK/Starter 独立解压验证及本地平台同步检查已通过。普通、拍照、手势、签到码、位置和签退协议已有测试账号成功回执；追加的九宫格滑动交互进行 JVM 自动测试，按用户要求不再运行模拟器。人脸与动态二维码实测已跳过，静态二维码及二维码组合场景尚缺教师端二维码内容，未宣称实测通过。

本次交付为 App 测试构建。插件、SDK、网站和审核工具链改动保留在本地，线上同步与正式推广尚未执行；正式推广仍须通过现有平台一致性检查。
