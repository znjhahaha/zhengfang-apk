# 1.0.114 恢复预览版功能并改进插件交互

## notes

- 恢复 1.0.112-ui-preview 中遗漏的登录首页布局、透明 Logo、学校选择分组与操作入口，以及中性按钮底色。
- 恢复按页面显示的加载图标动画、内容进入时的阴影空间和启动动画透明终帧，保持预览版的样式及动画时序。
- 恢复课表刷新时的浏览状态保留，账号切换仍相互隔离；补齐周视图、日程、课程详情中的实际日期和调课信息。
- 恢复节假日参考、整日停课与补课、单次课程调整；课表、桌面小组件、通知和日历导出共同使用调整后的时间与地点。
- 恢复按账号设置默认提前提醒时间及单门课程覆盖；通知打开对应的实际课程，并兼容此前保存的提醒设置。
- 恢复小组件背景图片、透明度、模糊和卡片外观设置，补齐组件配置入口、布局及点击区域。
- 修复地图子页与父页内容叠在一起的问题，调整地图渲染与页面退出时的生命周期；增加加载、超时提示和重试，地图未加载时仍可搜索、选择和保存地点。
- 优化插件表单：固定标签、清空、密码显示、多行输入及键盘搜索；连续输入和拖动优先显示最新值，避免较慢的旧响应把输入或滑块拉回。
- 插件可声明子页标题和返回事件，支持系统返回、进入/退出动画，以及每个页面的独立滚动位置；减少快速操作时进度条闪烁。
- SDK 升级至 3.6.0，API 主版本仍为 3，新增可选 ui.navigation@1；同步 CLI、模板、网站文档与审核规则，已有插件保持兼容。
- 保留 1.0.113 的树维 EAMS、超星智慧教务和 ARM64/ARM32 分包更新。本次为非强制正式更新；学习通 0.2.1 的签到预填写功能随本地插件包单独交付，不发布到插件市场。
