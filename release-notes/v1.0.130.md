# App 1.0.130

## notes

- 考试页面支持离线新增、编辑、删除；手动记录与教务查询共存，编辑教务考试形成手动覆盖，删除覆盖恢复最新教务记录。
- 成绩和考试保存本地最新版，进入页面、切换栏目或学期先显示缓存再同步；查询失败保留旧数据，按账号和学校配置隔离。
- 新增安徽工业大学本科 VPN/CAS 网页登录与旧强智配置；修复强智密码框仅有 id 的识别及网页登录完成地址。
- 完善插件桌面小组件的周期刷新、手动刷新、配置绑定、多实例数据、账号切换、倒计时和停用清理；新增可保留初始值的宿主日期与时间滚轮能力。
- 同步 SDK 3.8.0 / API 3、网站开发包和公开审核工具链；小组件和四项滚轮能力最低 App 130。

## verification

本地 Android 全量单测 1512 通过、5 项可选/实网跳过；Android SDK 官方模拟器九项设备测试通过，涵盖手动考试、覆盖恢复、历史日期、周期/即时 Job、多实例及合成网页登录返回。MuMu 尚未验收。

安徽工业大学真实浏览器认证与只读查询通过；成绩/考试为空，未开放选课轮次。真实 App 登录和实际选退课待验收，此版本不代表学校所有功能已实网通过。
