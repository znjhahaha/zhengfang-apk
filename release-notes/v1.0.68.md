## notes

本次带来全新的液态玻璃界面，并新增自定义壁纸与浙江工业大学登录支持。
界面：整套控件重做为液态玻璃质感，按压、拖动、切换都有真实的形变与回弹。
壁纸：可选预置背景、纯色或自己的照片，支持模糊与暗化调节；界面颜色会跟着壁纸自动适配深浅。
课表与成绩：顶栏改为随滚动收起，一屏能看到更多内容；筛选面板改为浮层，不再顶掉列表位置。
登录：新增浙江工业大学统一身份认证；密码加密保存在本机，登录过期时自动续期，不必反复重登。
小屏适配：针对 16:9 等较短屏幕重新计算了布局间距，弹窗按钮和列表末项不会再被系统导航栏挡住。
修复：修复自定义壁纸选图偶尔失败、抢课页与成绩页部分文字被遮挡、以及切换选项时指示器错位的问题。
其他：清理了界面文案与日志中的表情符号，应用名统一为正方教务助手。

## changelog

<!-- 这一段进 CHANGELOG.md 归档，可以用 Markdown。 -->

### 界面与交互

- **液态玻璃体系重做**：按钮、开关、分段控件、选择器统一到同一套光学管线（折射 + 色散 + 镜面高光），按压形变改为各向异性挤压配合弹簧回弹；相邻控件在按压靠近时会以 SDF 平滑并合，松手后分离。
- **顶栏随滚动收起**：课表与成绩页的顶栏改为可折叠玻璃条，折叠行程严格等于两态高度差，因此收缩与滚动 1:1 对消、全程跟手。
- **筛选面板改为浮层**：不再在布局流中展开，列表滚动位置得以保留，面板本身折射其后的课程卡片。
- **浮动通知**：页内提示改为单个元素在胶囊与长条之间连续形变，顶栏会上报自身底边，通知不会压住顶栏按钮。

### 壁纸与外观

- **自定义壁纸**：支持预置背景、纯色与本机图片三种来源，统一走同一条渲染路径；导入时按 EXIF 方向校正并降采样重编码。
- **模糊与暗化**：图片壁纸可调模糊与暗化。模糊用三遍 box blur 近似高斯，因此在 API 24 上同样可用，不依赖 RenderEffect。
- **随壁纸自适应**：顶栏文字与玻璃控件的深浅依据壁纸对应区域的 Rec.709 亮度决定，并带迟滞阈值防止边界抖动。

### 登录与账号

- **浙江工业大学统一身份认证**：新增 CAS 三阶段登录（登录页 → RSA 加密提交 → 服务票据重定向链），处理验证码开关与 flow-execution 重试。
- **凭据加密留存**：密码经 AndroidKeyStore AES/GCM 加密后保存在本机；任何失败一律降级为空，不会崩溃。
- **静默续期**：会话过期时先尝试单飞续期，成功则继续，失败有 60 秒冷却；Cookie 看护不再在首次过期后永久停止。

### 屏幕适配

- **连续系数替代尺寸分档**：新增 `ScreenMetrics`，以纵向/横向紧凑度两个连续系数插值原有写死几何。两个系数在 20:9 上恰好为 0，因此主力比例观感零变化。
- **底栏几何收敛到单一来源**：轨道高度与内容留白此前各算一套（底栏 `8+72+8+navBar`，各页写死 96dp），三键导航下列表末项有 16dp 被遮挡。现统一由 `NavBarMetrics` 导出。
- **弹窗安全区**：安全区改在宿主层施加。卡片本身无限高且部分正文为 `heightIn(max = 420.dp)`，此前在 640dp 屏幕上确认按钮会落到导航栏之下。

### 性能

- 玻璃渲染按运行时能力分档，低能力设备回退到透镜采样而非实时模糊；标签切换与页面转场的合成层数量下降。

### 修复

- 自定义壁纸选图：`inJustDecodeBounds` 按约定返回 null 曾被误判为打开失败，导致所有图片导入失败。
- 开关拖动与外部状态互斥导致的竞态；分段控件在顶栏折叠期间因宽度逐帧变化而丢失拖动状态。
- 拖动饱和按位移模长计算，消除对角方向 1.41 倍过冲造成的八向摇杆感。
