# v1.0.81

## notes

新增插件中心，支持下载学校适配、导入插件、更新回退和开发预览；已有学校与统一认证登录继续保留。
新增独立校园服务页面，服务账号与教务账号分开管理，支持模块排序、隐藏和恢复。
开放原生扩展：表格、时间线、柱状图、网格入口、多行文本和开关；服务可在课程首页、课表和成绩页提供入口。
插件扫码、文件选择、通知与日历操作需要逐次授权，切换账号或停用插件后旧结果失效。
新增简洁单课、双课程和今日时间轴桌面组件，完善课表日期栏、日周切换与页面恢复。
改善网页登录布局、教务地址识别和已有 CAS 登录流程，修复三亚学院旧强智登录协议判断。
修复正方接口路径与参数处理、教学班匹配和旧队列兼容，选课队列等待重试时继续轮询其他课程。
优化底栏图标动画收尾与连续点击反馈，更新构建工具和运行依赖。
App 使用反馈问卷已上线，欢迎反馈使用场景、功能体验和插件需求；插件开发者可加入 QQ 群 1074017033。

## changelog

本版本覆盖上个已发布版本 v1.0.80 之后的全部功能提交：17ada56、e4dcef7、2006acf、2ba12d5、821da95，以及本次 API v3 原生扩展。main 已合入的 #25 内容也包含在发布范围内。

### 教务与课表

- 保留太原科技大学、浙江工业大学、湖南工业大学以及通用正方 CAS 的已有登录实现。配置和局部扩展插件复用本体登录，只有显式覆盖 auth 组时才改由插件认证。
- 完善教务地址识别与路径前缀处理、正方选课请求和教学班身份匹配；旧队列按唯一证据重绑，不在精确模式下自动替换其他教学班。
- 修复三亚学院旧强智登录页残留 flag=sess 脚本导致的协议误判，优先识别实际按钮的 Base64 提交流程。
- 调整网页登录页面布局；抢课队列等待重试时释放工作名额并轮询其他课程。
- 保留现有玻璃视觉，完善悬浮日期栏、日周课表恢复、学期和账号隔离；新增三类桌面组件。
- 平滑底栏图标动画收尾与连续点击反馈。

### 插件与校园服务

- 插件中心支持正式签名目录、导入、安装、停用、更新、回退和开发预览；下载时检查签名与摘要。
- API v2 校园服务使用独立登录和会话，提供声明式原生页面、模块排序与显示设置。服务写入先确认，结果未知时不自动重试。
- API v3 兼容 v1/v2，增加 keyValue、table、timeline、barChart、grid 组件及 multiline、toggle 表单字段。
- 正式服务插件可声明课程首页、课表、成绩页入口，入口显示按账号、插件和位置隔离保存。
- 扫码只回传文字；文件仅读取用户选定内容，最大 64 KiB；通知标明插件来源；日历打开系统编辑器，是否保存由用户决定。每次操作都单独确认，回调只能进入声明的查询操作。
- SDK、CLI、六类模板、开发网站和工具包同步更新。开发者交流 QQ 群：1074017033。

### 问卷与构建

- 问卷星 12 题使用反馈已接入 App 问卷后台，并开启重要提醒。覆盖使用场景、功能评分、问题、改进优先级和插件需求，学校与文字建议选填。
- Kotlin 更新为 2.4.10，协程更新为 1.11.0。

### 验收边界

- 503 项 JVM 测试通过；4 项需要真实账号的在线测试未启用。SSO 相关回归通过，本轮未重新测试真实学校账号，也未执行真实选退课。
- API v3 原生页面、表单、授权拒绝、文件选择、通知来源、账号与会话失效，以及旧插件流程通过模拟器验证。
- 正式目录保留此前验收的三所学校。华南师范大学成绩明细与校园服务仍是开发模板；黑龙江工程学院网络问题、南京工程学院真实查询验收不在本次已解决范围内。
- 新系统能力需要对应插件实现，不能将模板样本通过视为真实校园服务上线。相机实际解码和日历保存没有在本轮验收中执行。
