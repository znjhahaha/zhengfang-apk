# v1.0.82

## notes

插件中心改为“本校／已安装”视图，集中展示生效状态；介绍、作者、权限、兼容要求和验收记录放入插件详情。
安装后按学校域名、端口和路径匹配适配，支持手动选择、冲突处理和本校停用，已有插件继续兼容。
新增通用原生插件框架，可组合页面、表单、虚拟列表和绘图，通过统一事件实现异步流程及持久状态。
开放受限文件、隔离存储、凭据与会话、设备交互、任务、通知和导航能力，保留已有校园服务页面挂载与扫码等功能。
问卷改用弹窗合并提醒，同一自然日最多提醒一次，完成后停止提醒，并避让更新提示。
课表顶栏收起时隐藏日周切换和今天按钮，操作仍可通过更多菜单访问，展开时恢复。
设置、插件详情和运行错误处增加快捷反馈，站内可提交问题并查看回复，公开反馈同步 GitHub Issue。
插件网站管理端重新设计，支持后台上传、审核、验收签名、发布与便捷上下架；邮箱登录保留 Cloudflare 人机验证。
开发者中心同步八个模板、API v3 开发套件和完整文档，欢迎各校开发者加入 QQ 群 1074017033。
清理 APK 仓库，SDK 和网站独立维护，移除统计服务源码、开发参考文档和临时文件，重新编写使用说明。

## changelog

覆盖 v1.0.81 之后的通用原生插件、本校适配、问卷提醒与课表顶栏改动，并整合已发布的校园服务扩展；已有学校业务适配继续保留。

### 插件框架

- API v3 增加 `kind: native`，以 `ui.init`、`ui.reduce` 返回状态、组件树和宿主效果。页面、入口、菜单、数据提供者与任务通过 `contributes` 注册。
- 新增版本化能力注册表、权限与限额控制、受限文件句柄、凭据和会话管理，以及有界异步流程。QuickJS 保持隔离，副作用交由宿主确认，结果未知时不自动重放。
- 学校、账号、页面与包版本分别绑定，切换上下文后丢弃过期结果；运行中的后台任务沿用原作用域。
- 保留 API v1/v2、旧包导入、原校园服务模块、v3 页面挂载、扫码、文件选择、通知和日历操作。
- SDK、CLI 和网站上传校验统一支持两种 v3 类型；新增校园服务扩展示例、严格的文件结果与日历参数校验。

### App 体验

- 学校匹配支持域名规范化、签名目录别名、端口和路径；手动选择优先，多个候选需选择并记忆。本校停用与卸载分开。
- 精简插件中心，增加作者与功能介绍、公开验收记录、匹配范围和反馈入口；导入、回滚及开发工具移入更多菜单。
- 本校有效且未完成的问卷使用合并弹窗，每自然日最多提醒一次；迁移旧提醒状态，避让更新及其他阻塞弹窗。
- 课表沿用现有滚动形变，折叠时将日周切换和今天按钮移入更多菜单，保持日期与课程列对齐。

### 网站与仓库

- 管理端增加独立导航、上传入口、投稿审核、发布预检、上下架与操作记录，适配手机和深色模式。
- 邮箱登录、Turnstile、访客记录归集、作者控制台、私密反馈与公开 Issue 同步已接入站内流程。正式发布需完成真实验收和签名，上传源码不会在服务器执行。
- SDK 真源、开发工具与网站移入独立插件仓库；APK 仓库仅保留 App 所需运行资源、构建、测试与发布文件。删除无关服务、参考文档、IDE 文件及旧截图，完全重写 README。
- 设备回归脚本支持显式 ADB 路径与 SDK 环境变量，兼容 Android 7 截图，并预置预览包的通知测试权限。

### 验证

- 523 项 JVM 测试：519 项通过，4 项需真实账号的测试跳过；调试包、独立预览包和设备测试包构建通过。
- 网站 35 项接口／集成测试与 SDK 20 项测试通过；发布套件解压后完成环境检查、创建模板、离线测试和打包。
- 本地设备与 Lint 复测未全部完成，发布流水线将继续执行构建检查。
- 本轮不重新执行真实学校选退课，模板验证不代表真实学校业务已完成适配。
