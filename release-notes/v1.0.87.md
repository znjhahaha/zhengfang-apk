# v1.0.87

## notes

设置的外观分组新增底部导航栏自动收起开关，默认开启；关闭后立即展开并保持展开，重启后保留选择。
修复学校网址识别时的主线程网络异常，响应读取、关闭与页面解析统一在后台执行。
登录页新增学校插件入口，无需登录即可安装签名插件、导入插件包并选择本校适配。
使用适配后可直接返回登录页，保留学校与学号，清理旧验证状态，避免旧回调干扰新的登录。
学校列表支持移除自行添加的测试学校，保留插件、账号和课表，同域不同路径的教务系统可分别添加。
修复周课表滚动到底部时的回跳，各分页独立保存滚动状态，切周继续保留阅读位置。
课程状态标记预留固定空间，当前课程和下一节更新时不再改变课表行高。
插件详情与操作确认统一使用玻璃弹窗，增加对话框、底部弹层和展开菜单的底色遮盖，让文字更清晰。
修复三亚学院旧强智首页的姓名读取，完整保留姓名并分离身份标签。
插件可在签名清单中按学校或网络规则声明 User-Agent，适配按请求标识拦截的学校；同步 SDK 3.0.1 与开发文档。
学校网址识别异常提供可复制的错误报告；崩溃后再次打开可查看报告，并通过快捷反馈提交。
重设计单课、双课、今日时间轴三种桌面组件，默认分别为 1×1、横向 2×1 和 2×2，旧组件无需重新添加。
桌面组件随实际尺寸、浅深主题和字体大小调整内容，保留离线课表与点击跳转，选择页同步紧凑预览。

## changelog

### 桌面组件发布校验修复

- 1.0.85 的 CI 报告记录 523 项 JVM 测试、1 项失败、4 项跳过。唯一失败为 ScheduleWidgetTest 的旧布局断言：紧凑双课卡实际显示 08:00，测试仍要求完整时间段 08:00–08:45。
- 按已确认的组件设计更新尺寸样例：窄卡显示开始时间，较宽卡显示完整时间段；双课形态在窄尺寸下仍保留第二门课，按可用高度显示教室和状态。
- 保留可见文字的高度和边界检查、两门课分别跳转与账号隔离检查；覆盖 130×56 最小尺寸下整卡进入当日课表，检查紧凑卡的无障碍描述仍包含完整时间段。
- 修改限于失效的组件测试及发布资料，不删除或跳过测试，不修改组件的既定展示行为。按要求未在本地运行测试、构建或 Lint；已核对远端失败报告并完成静态语法、差异和发布资料检查。

### 底部导航栏开关

- 在“设置 → 外观”中新增“底部导航栏自动收起”，默认保留向下浏览收起、向上浏览展开的行为。
- 关闭后底栏立即展开并保持展开；通过外观设置持久保存偏好，重启后继续生效。
- 设置切换时重置收缩状态与滚动方向累计值，避免重新开启时沿用旧手势；保留玻璃底图刷新和课表顶栏形变。
- 新旧设置入口均连接同一偏好。仅完成 Kotlin 静态语法检查、差异检查与调用链核对，未运行本地构建、测试或设备验证。
- 整理日志时，GitHub 最新带 APK 的正式版本仍为 1.0.83，因此下列条目保留其后的累计更新；1.0.85 在上述组件测试处失败，1.0.86 也包含同一旧断言。

### 网址识别闪退与发布恢复

- 使用 GitHub 正式版 1.0.83 APK，在隔离的 API 32、API 37 模拟器中分别输入北京化工大学教务网址并点击识别，均捕获主线程 NetworkOnMainThreadException；API 37 将地址改为 .com 后显示连接失败，进程保持运行。
- 根因是 OkHttp 回调仅异步取得响应头，页面协程恢复后仍在主线程读取和关闭响应体。识别入口已通过 Dispatchers.IO 执行整个请求与解析流程，保留取消与过期结果隔离；不修改玻璃渲染、域名后缀判断或 HTTPS 跳转限制。
- 1.0.84 的发布在公告校验阶段因缺少版本公告 JSON 终止，未生成正式安装包。本版本保留其修复，并包含上一个实际发布版本 1.0.83 之后的全部应用更新。
- 补齐 1.0.85 发布公告；发布脚本在写版本文件和创建标签前，调用与 CI 相同的公告校验，避免缺失公告时生成不可移动的发布标签。
- 用户提供的另份日志属于 1.0.77，异常为 School has no selected academic adapter。对应的会话巡检在 1.0.81 已增加适配器就绪判断并将创建操作移入后台处理，不能将该旧日志当作本次网址识别闪退的证据。

### 课表与弹窗

- 分离周／日分页的纵向滚动状态，只有活动页面驱动顶栏与位置保存；位置恢复在测量后执行一次，并让位于用户拖动。
- 预留课程状态标记高度，保持时间栏、网格和课程跨度使用同一行高。
- 将插件中心、开发工具、校园服务及原生插件页面纳入同一窗口的玻璃宿主，统一操作确认弹窗。
- 弹出表面的不透明度下限调整为浅色 0.78、深色 0.84、高对比度 0.96，保留折射和开合效果。

### 登录前学校适配

- 登录页学校选择器下方常驻学校插件入口，错误提示提供快捷检查入口。
- 插件中心接收独立的目标学校，支持签名包导入、选择适配、添加插件学校和返回登录，不切换既有登录账号。
- 返回结果包含学校、提供者与安装变更标记；旧请求与挑战失效，用户重新点击登录后才发起新请求。
- 学校管理支持删除自行添加的学校条目，阻止移除正在登录的学校，保留账号、课表与插件；重复地址判断区分协议和应用路径。

### 学校兼容与错误报告

- 修复 #24：旧强智解析独立姓名段落，不拼接相邻身份标签；兼容 xsMain_new.htmlx 个人资料入口。修改限定于旧强智身份读取。
- 修复 #28：新增 school.userAgent 和 network[].userAgent，选择完整匹配且路径最具体的网络规则，按规则、学校、默认值依次取值；每次跳转重新匹配。
- User-Agent 限制为 1–512 个可打印 ASCII 字符，不接受换行和首尾空格；不扩大网络、请求头与会话权限。SDK 3.0.1、CLI 离线样本、Schema、示例与网站下载已同步。
- 增加独立错误报告页面、复制和快捷反馈入口。Java/Kotlin 未处理异常在退出前保存，下次启动提示；API 30 以上同时读取系统记录的原生崩溃和 ANR 摘要。
- 错误报告保存在不参与备份的本机目录，只记录类型、调用栈、版本、设备和固定操作阶段，不记录异常消息、账号、Cookie 或学校响应，不自动上传。

### 桌面组件

- 保留单课、双课和今日时间轴三个 Provider，采用接近实色的浅深背景、简洁分隔与紧凑的信息排布。
- 默认尺寸调整为 1×1、2×1 和 2×2；支持新版桌面的尺寸列表及旧版横竖屏尺寸，按实际空间裁剪辅助信息。
- 继续使用本地课表快照、账号校验、刷新调度与课程跳转；选择页使用真实渲染器显示比例一致的预览。
