# v1.0.88

## notes

周课表、日课表及三种桌面组件完整显示课程名和教师，长名称自动换行，小组件随尺寸调整字号。
桌面组件保留时间与教室，时间轴优先显示完整课程，拉大后可查看更多安排。
修复日期标题左侧缩进、跨月对齐和选中星期偶尔残留旧日期的问题，保留数字切换动画。
修复课表滚动到底部回跳、翻页覆盖当前日期等问题，切换主题和返回应用时保留浏览位置。
课表优先显示本地缓存并在后台更新，切换页面共享正在进行的请求，减少重复加载和提示。
修复部分设备插件进程启动或绑定失败，完善取消、超时和连接中断后的处理。
插件中心提供发现与已安装页面，统一搜索框、学校筛选、插件卡片和操作按钮，已有目录可离线浏览。
恢复开关滑动与回弹动画，支持点按整个开关区域和快速反向切换。
项目 README 补充真实界面截图、开关动图、小组件说明和常见问题。
增加 API 3 学校统一认证支持，完善网页登录凭据、认证回调与跳转兼容。
内置湖北汽车工业学院金智教务与山东石油化工学院乘方教务，无需额外导入适配；乘方使用官方网页登录，目前不支持选退课提交。
完善旧强智课表、选课轮次与查询表单解析，支持部分正方学校的个人课表入口。

## changelog

### 课程与桌面组件

- 周／日课表完整显示课程名和教师；周视图根据完整文字测量行高，保持时间栏、课程跨度与滚动位置一致。
- 单课、双课程、时间轴均加入完整教师信息，使用实际 TextView 字体度量处理换行和非线性字体缩放，不再用省略号截断课名与教师。
- 小尺寸保留开始时间和教室编号；时间轴优先减少行数，拉大后显示完整时间段及更多课程。组件选择页同步预览与无障碍描述。

### 日期、滚动与动画

- 日期标题将一位数月份的预留空白移至末尾，与周次文字左对齐，同时保留跨月时的整体宽度与动画。
- 日期条使用实时文字层，避免选中星期的玻璃快照覆盖新日期；其他分段控件继续使用既有文字折射。
- 课表分页只在实际用户滚动后回写所选日期，避免初始化和程序跳转覆盖父级周次。修改当前学期开学日期后定位今天。
- 各页面保留独立滚动状态，移除局部过度滚动效果，并处理恢复位置与快速反向操作的竞争。
- 开关松手后从当前滑块位置继续弹簧动画，扩大点击范围，保留拖动取消、禁用、无障碍和快速反向切换的行为。

### 缓存刷新与校园插件

- 课表使用 Activity 级协调器，按账号会话、学校与学期共享请求，自动加载增加短时冷却，切换账号后取消旧请求。
- 缓存先显示，自动刷新将静默反馈传递至网络和会话处理；手动刷新仍可提升交互反馈。区分有效空课表与错误响应。
- 修复 #30 相关的插件服务启动与绑定兼容问题，处理超时、取消、空绑定、进程死亡和迟到回调，关闭传输文件描述符。
- 插件服务改为非导出的普通私有进程，与应用共享 UID；QuickJS、主机接口授权、包签名和资源限制继续生效。已发出的修改请求中断后保留结果未知状态，不自动重放。
- 插件中心增加发现与已安装入口，支持签名目录缓存、本地搜索、学校筛选和安装／使用操作；搜索、筛选、卡片与按钮采用统一组件。

### 学校统一认证与内置教务

- 合入学校 SSO 分支的两个提交，支持 API 3 教务插件的认证令牌、网页登录 Cookie 绑定、认证回调片段、受限 HTTPS 回调升级和 AES-ECB 兼容；令牌不随跳转发送到其他站点。
- 内置湖北汽车工业学院金智与山东石油化工学院乘方适配，支持按教务地址或指定认证入口识别、登录／会话恢复，以及课表、成绩、考试和作息查询；已安装的官方适配与手动选择仍保留优先级。
- API 3 配置和扩展插件可继承内置金智／乘方协议，必须显式声明本校配置与网络权限；不把参考学校的地址或权限带入其他学校。乘方选退课提交仍未支持。
- 改进旧强智课表单元格与多表单解析，识别选课轮次、学校声明确认和关闭状态，修复动态查询参数；补充部分正方学校个人课表菜单与权限判断，以及登录页和会话恢复处理。
- 合并保留学校识别的后台线程修复、学校自定义 User-Agent，以及按每次跳转目标生成的同源 Referer；增加组合回归断言，避免覆盖现有兼容处理。
