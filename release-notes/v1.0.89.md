# v1.0.89

## notes

登录页新增学校搜索，整合已保存学校和插件目录，选择适配并确认权限后即可使用。
同校不同作者的插件可经授权复用已有教务登录，支持查看和撤销授权，独立服务保留各自账号。
校园服务支持自己的 X-Token 验证，按声明的学校、域名和路径使用，兼容学校自定义 User-Agent。
插件页面、服务账号和本地数据按学校与账号隔离，更新先暂存，新增权限确认后生效，运行中的任务继续使用原版本。
作者升级插件沿用原插件 ID，版本历史集中展示；功能标签独立显示和搜索，查看功能更方便。
插件详情增加当前版本的公开源码入口，支持参与修复和保留原作者信息的独立衍生。
可一次设置所选学期的课前提醒，按本地课表和节次安排通知。
修复小尺寸桌面组件的教室截断，完整保留课程名、教师、时间和教室，并根据空间调整文字。
日期与星期保持对齐，数字继续滚动切换，适配一位变两位、跨月及快速反向操作。
完善河南财经政法大学等正方系统的登录回调兼容，识别教务系统的选课关闭提示。
插件平台升级至 3.2.1，统一六类教务协议的版本化插件入口，保留已有插件兼容处理。
同步 SDK、使用文档与开发网站，简化开发流程，提供适合 Agent 使用的提示词及独立 SDK 下载。
更新项目 README、真实界面截图和使用说明，补充学校搜索、插件授权、小组件及日期动画说明。

## changelog

### 学校搜索、插件与授权

- 登录页合并已保存学校与通过签名验证的插件目录，支持搜索、兼容性判断和多个适配候选；下载校验、权限确认及激活完成后才绑定学校，保留已有自定义地址。
- 同一学校的不同作者插件可申请使用宿主管理的教务会话。授权限定学校、账号、插件版本和网络范围，可查看与撤销；密码、Cookie 等原始凭据不交给功能插件，独立认证服务保留独立账号。
- 校园服务支持自有 `X-Token`，通过精确网络声明和 `network.request@3` 使用；每次重定向重新校验目标范围，保留学校自定义 `User-Agent` 与已有请求兼容处理。
- 插件平台 3.2 / 3.2.1 增加稳定页面入口、网页与服务账号隔离、本地数据分区、凭据绑定和宿主侧凭据转换；移除凭据后使对应句柄失效。
- 服务工作流固定依赖版本，兼容更新先暂存，新增权限经确认后激活；支持数据迁移，进行中的任务继续使用原版本，完善停用、卸载、回滚和授权失效处理。
- 插件升级保持稳定 ID，后台将版本归入同一插件；功能标签独立于简介展示、筛选和搜索。
- 插件详情提供当前安装版本的公开源码、许可证、摘要和仓库入口。源码下载与版本绑定，支持向原维护者提交修复，或保留归属及许可证、使用新 ID 独立衍生；未公开源码的历史版本会明确提示。

### 课表、小组件与日期

- 增加整学期课前提醒入口，可一次设置所选学期的课程提醒；根据本地课程、教学周和节次生成安排，并处理权限、账号和课表变化。
- 修复小尺寸单课、双课程与时间轴组件的教室截断。使用实际 TextView 字体度量分配空间，完整保留课名、教师、时间与教室，不再仅提取教室编号；补充小尺寸、长名称和字体缩放回归。
- 星期和日期共享列中心及文字基线，保留数字滚动；处理单／双位变化、跨月、快速反向切换及减少动态效果设置，避免中间帧挤压或错位。

### 教务协议与登录兼容

- 新／旧正方、新／旧强智、金智和乘方六类教务协议统一经过版本锁定的 TypeScript 插件包入口，保留旧插件入口及学校差异配置。
- 完善河南财经政法大学教务登录的受限 HTTPS 回调和 RSA 标记解析，识别选课关闭页面，避免将关闭状态作为可提交表单；跳转仍需符合配置的学校主机范围。
- 固定内置教务包索引与元数据的换行约定，保持包摘要、签名及跨平台校验一致；合并保留 v1.0.88 的界面、缓存刷新、诊断和学校请求兼容修复。

### SDK、网站与文档

- 同步 SDK 3.2.1 / API 3 的协议、类型声明、宿主资源、示例、完整开发套件和独立 SDK 下载，提供版本绑定的源码协作与迁移说明。
- 开发网站简化为分步流程，折叠参考内容；使用文档及面向 Agent 的提示词与 SDK 从同一来源生成。作者后台按稳定插件 ID 管理版本，功能标签单独维护。
- README 统一使用当前应用名称并说明可复用教务协议，补充学校搜索、授权、升级、小组件和数字动画用法；新增六张真实界面截图并记录版本与来源。独立的旧内置教务说明已整合至现有说明，修复相关失效链接。
- 发布前主线验证：JVM 共 693 项，689 通过、4 项门控跳过；MuMu 日期与插件中心回归 6 / 6；独立解压开发套件 166 / 166，独立 SDK 构建及导出校验通过；网站 54 / 54、类型检查与构建通过。设备回归使用演示数据与测试插件。
