# 112preview 与 1.0.113 的源码差异核对

用户指定的对照版本是 `1.0.112-ui-preview`，不是 1.0.103。112preview 的交付清单记录基线为 `ddbe142804248b1e3eba39b2e61eeccc82dc3e73`，实际产物来自包含未提交改动的工作区。1.0.113 的源码为 `9b0ad5335847dc5f537a0f2cf1f076b2d50acb25`；分支历史已合入，但预览包中的部分未提交 App 改动遗漏。

## 范围与恢复方法

逐项核对整个 App 的生产源码、资源、清单与 JVM 测试，共发现 35 个已修改文件和 16 个新增文件没有完整进入 1.0.113。对照原始未混淆 112preview APK 的 DEX，确认新增的 9 个生产 Kotlin 文件均已编译进预览包；同时核对预览版交付记录与当前保存的工作区。

| 模块 | 本次补回内容 |
| --- | --- |
| 登录首页与学校 | 布局、透明 Logo、学校分组选择、搜索/管理操作和中性容器色 |
| 启动与页面加载 | 透明终帧退出、页面专属加载图标、非活动页停止动画、模块入场阴影空间 |
| 课表浏览 | 刷新不重建浏览会话、账号隔离、课程实际日期、调课后的周视图与日程 |
| 课程调整 | 节假日参考、整日停课/补课、单次取消/移动/改节次/改地点、失效规则提示 |
| 提醒 | 账号默认提前量、单课覆盖、旧数据兼容、调整后通知与课程详情定位 |
| 桌面小组件 | 外观配置页、背景图片/透明度/模糊、卡片布局、配置入口和实际课程跳转 |
| 日历导出 | 与课表、提醒和小组件共用课程日期展开，输出调整后的时间、地点与稳定身份 |

按 112preview 开发工作区相对于已提交基线的补丁进行三方合并，没有覆盖 1.0.113 整个目录。唯一重叠的产品文件是 `SchoolSearchPicker.kt`，在恢复分组行式界面的同时，保留 1.0.113 新增的内置学校适配选择。原工作区和已交付 APK 保持原样。

## 构建差异

预览包的包名为 `com.tyust.course.uipreview`，使用调试证书，自动打开演示账号；正式包的包名为 `com.tyust.course`，使用官方证书并正常登录。这些构建差异继续保留，预览包的演示数据不作为正式功能。学习通插件独立交付，不包含在本次 App 修复提交内。

修复使用新的 1.0.114 版本号，保留 1.0.113 的原始包与哈希，继续提供 ARM64、ARM32 和旧更新器使用的 ARM 通用兼容包。SDK 升至 3.6.0，API 主版本保持 3；正式推广继续经过平台一致性检查。

## 本轮追加的插件交互修复

恢复完成后，针对用户反馈追加了地图子页背景隔离、MapLibre TextureView 渲染与生命周期管理、可重试加载状态、统一表单输入框，以及异步输入回显协调。滑块和分段选择使用稳定节点，不随筛选值重建；新 ui.navigation@1 契约让宿主显示插件子页标题、处理返回动画，并按页面保存列表滚动状态。退出帧不再接收业务事件，同名节点在不同子页分别保存状态。

针对地图必须先开 VPN 的反馈，瓦片与主动地点搜索改从 `plugins.hidisiwa.xyz/api/maps/v1/` 获取，手机不再直连海外地图源；保留 WGS84，避免换源坐标偏移。服务只请求固定上游，校验数据格式与体积，缓存瓦片和地点，搜索采用跨客户端的全局限速；不携带学校或插件登录会话。上游故障显示失败，不伪造成功空结果。

恢复基础报告单独保留：50 个文件与原预览源码一致，另一个学校选择页为三方合并。追加修改后，49 个文件保持一致；GlassKit.kt 严格验证只增加 maxLines 参数及其转发，不放宽其他文件的比对规则。原始脏工作区文件摘要仍逐个复核。

学习通插件的“填写”按用户澄清实现为预填写：照片、人脸资料和课程地点可以提前准备，手势、签到码、静态二维码绑定活动保存。动态二维码、拼图与当次人脸验证凭证不保存复用。插件源码与安装包仅本地交付，未纳入 App 或平台仓库的发布内容。

## 验证边界

验证包括源码完整性、历史预览 APK 的静态检查、JVM 回归、Lint、构建、地图服务和发布产物校验。根据用户后续授权补充模拟器签到与 UI 测试，实际执行范围与结果单独记录；不把静态比对或单元测试写成真机视觉验收。最终测试和发布状态以对应 CI 及交付收据为准。
